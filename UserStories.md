# Easy Peasy France — User Stories

## 1. User Stories

Les **user stories** décrivent les besoins fonctionnels d’**Easy Peasy France** du point de vue des différents profils. Elles guident le périmètre du MVP et la priorisation.

### Visiteur (non connecté)

| Priorité | En tant que... | Je veux... | Afin de... |
|---|---|---|---|
| P1 | visiteur | découvrir la mission et les services d’Easy Peasy France | comprendre l’intérêt avant de m’inscrire |
| P1 | visiteur | consulter la page FAQ | obtenir des réponses rapides sans créer de compte |
| P1 | visiteur | accéder à la page Contact | poser une question ou signaler un problème |
| P2 | visiteur | lire des témoignages d’utilisateurs | me rassurer sur la fiabilité du service |
| P2 | visiteur | m’inscrire ou me connecter | accéder à un espace personnalisé |

### Utilisateur inscrit (ROLE_USER)

| Priorité | En tant que... | Je veux... | Afin de... |
|---|---|---|---|
| P1 | utilisateur | accéder à un tableau de bord | voir mes informations et mes démarches principales |
| P1 | utilisateur | consulter la liste des démarches selon mon visa | savoir quoi faire et quels documents préparer |
| P1 | utilisateur | ouvrir les liens officiels et documents requis | effectuer mes démarches sans erreur |
| P1 | utilisateur | poser une question dans la communauté | obtenir de l’aide d’autres utilisateurs ou d’un conseiller |
| P1 | utilisateur | répondre/commenter les posts | partager mon expérience et aider les autres |
| P2 | utilisateur | ajouter un post en favoris | le retrouver facilement plus tard |
| P2 | utilisateur | prendre un rendez-vous (créneaux proposés) | rencontrer un conseiller Easy Peasy France |
| P2 | utilisateur | modifier mes infos (email, téléphone, mot de passe) | garder mes données à jour |
| P2 | utilisateur | supprimer mon compte | effacer définitivement mes données |
| P3 | utilisateur | recevoir des notifications internes | être informé quand quelqu’un commente mon post |

### Administrateur (ROLE_ADMIN)

| Priorité | En tant que... | Je veux... | Afin de... |
|---|---|---|---|
| P1 | administrateur | accéder à un dashboard d’administration | avoir une vue d’ensemble du site |
| P1 | administrateur | activer/désactiver des utilisateurs | modérer les comptes problématiques |
| P1 | administrateur | créer, modifier, supprimer des tâches administratives | maintenir les informations à jour |
| P1 | administrateur | créer/supprimer des créneaux de rendez-vous | organiser les disponibilités des conseillers |
| P2 | administrateur | gérer la FAQ (ajouter/éditer/supprimer) | garantir la pertinence des réponses |
| P2 | administrateur | consulter les témoignages | suivre la satisfaction des utilisateurs |
| P3 | administrateur | voir des statistiques globales | évaluer l’activité et les besoins |

## Priorisation

- **P1 — Must Have** : indispensables au MVP.  
- **P2 — Should Have** : importantes mais non bloquantes.  
- **P3 — Could Have** : améliorations futures.

> Ces user stories guident la conception, le développement et les tests du projet, en alignant besoins utilisateurs, objectifs produit et choix techniques.
